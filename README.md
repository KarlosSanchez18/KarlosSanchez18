## Selected work

### Lead Tracking & CRM System — UTMZAP

<img src="./assets/case-utmzap.webp" alt="UTMZAP lead tracking and CRM system" width="100%" />

Desktop + web system for agencies to track lead sources and campaigns before the contact reaches WhatsApp. It captures UTMs and ad identifiers, creates trackable campaign links, records click/lead events, and organizes contacts in a mini-CRM.

**Stack:** Electron, React, TypeScript, Next.js, Supabase, PostgreSQL, REST APIs.

[Read the case study →](./case-studies/lead-tracking-crm.md)

### AI Voice Operations — Sophie

AI voice receptionist built for a U.S. service business. The agent handles inbound calls, qualifies leads, collects structured customer information, and automatically sends a call summary to the team through WhatsApp.

**Stack:** Vapi, webhooks, APIs, Docker, Linux/VPS, WhatsApp integration.

[Read the case study →](./case-studies/ai-voice-operations.md)

### Distributed Browser Automation

Distributed browser automation for operational data collection across remote agents and a central server, with concurrency control, session recovery, monitoring and operational routines.

**Stack:** Python, Playwright, Django, PostgreSQL, Linux.

[Read the case study →](./case-studies/distributed-browser-automation.md)

### Marketplace Payment Infrastructure

Custom WooCommerce / Dokan / Asaas integration for marketplace payment splitting, with multi-vendor rules, validations, refunds/reversals, idempotency and automated tests.

**Stack:** PHP, WordPress, WooCommerce, Dokan, Asaas API.

[Read the case study →](./case-studies/marketplace-payment-infrastructure.md)

### SaaS Benchmarking Platform

SaaS application for service benchmarking and operational analysis, including authentication, company/user management, trial rules, CSV uploads, metric processing, dashboards and an admin area.

**Stack:** Next.js, TypeScript, Supabase, PostgreSQL.

[Read the case study →](./case-studies/saas-benchmarking-platform.md)
