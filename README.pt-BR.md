## Projetos selecionados

### Lead Tracking & CRM System — UTMZAP

<img src="./assets/case-utmzap.webp" alt="UTMZAP — sistema de rastreamento de leads e CRM" width="100%" />

Sistema desktop + web para agências rastrearem a origem de leads e campanhas antes do contato chegar ao WhatsApp. Captura UTMs e identificadores de anúncios, cria links rastreáveis, registra eventos de clique/lead e organiza os contatos em um mini-CRM.

**Stack:** Electron, React, TypeScript, Next.js, Supabase, PostgreSQL, APIs REST.

[Ver o case study →](./case-studies/lead-tracking-crm.md)

### AI Voice Operations — Sophie

<img src="./assets/case-ai-voice.webp" alt="AI Voice Operations — Sophie / TRJ Clean Service" width="100%" />

Recepcionista de voz com IA desenvolvida para uma empresa de serviços nos Estados Unidos. O agente atende chamadas, qualifica leads, coleta informações estruturadas do cliente e envia automaticamente um resumo da ligação para a equipe pelo WhatsApp.

**Stack:** Vapi, webhooks, APIs, Docker, Linux/VPS, integração com WhatsApp.

[Ver o case study →](./case-studies/ai-voice-operations.md)

### Distributed Browser Automation

Automação distribuída de navegador para coleta operacional de dados entre agentes remotos e um servidor central, com controle de concorrência, recuperação de sessão, monitoramento e rotinas operacionais.

**Stack:** Python, Playwright, Django, PostgreSQL, Linux.

[Ver o case study →](./case-studies/distributed-browser-automation.md)

### Marketplace Payment Infrastructure

Integração customizada entre WooCommerce, Dokan e Asaas para split de pagamentos em marketplace, com regras multi-vendedor, validações, refunds/reversals, idempotência e testes automatizados.

**Stack:** PHP, WordPress, WooCommerce, Dokan, API Asaas.

[Ver o case study →](./case-studies/marketplace-payment-infrastructure.md)

### SaaS Benchmarking Platform

Aplicação SaaS para benchmarking e análise operacional de atendimento, com autenticação, gerenciamento de empresas/usuários, regras de trial, upload de CSV, processamento de métricas, dashboards e área administrativa.

**Stack:** Next.js, TypeScript, Supabase, PostgreSQL.

[Ver o case study →](./case-studies/saas-benchmarking-platform.md)
