# Lead Tracking & CRM System — UTMZAP

## Overview

UTMZAP is a desktop + web system designed for agencies that need to understand where WhatsApp leads came from before the conversation starts.

The system combines trackable campaign links, attribution data, lead creation and a lightweight CRM so the agency can connect campaign activity with the contacts generated by it.

## Problem

Click-to-WhatsApp campaigns often make attribution difficult once the user leaves the ad platform and starts a conversation. The goal was to create a practical MVP that could preserve campaign identifiers, register the lead intent and give the agency a usable view of the resulting contacts.

## Architecture

### Desktop application

- Electron
- React
- TypeScript
- Supabase Auth

### Public/web layer

- Next.js
- REST endpoints
- public redirect route by campaign slug
- landing-page tracking integration

### Data

- PostgreSQL / Supabase
- ownership rules with RLS
- clients, campaigns, click events and leads

## Core flow

1. An agency creates a client and a trackable campaign link.
2. A visitor opens the public campaign URL.
3. The system captures attribution data and records the click event.
4. A lead-intent record is created.
5. The visitor is redirected to WhatsApp or a landing page while attribution parameters are preserved.
6. The agency can manage the resulting leads from the mini-CRM.

## Engineering decisions

- Keep the tracking layer independent from the desktop UI so public traffic can be received without exposing the authenticated application.
- Treat the MVP lead as **click/intent**, not as a confirmed WhatsApp conversation.
- Validate redirect destinations instead of blindly forwarding arbitrary URLs.
- Preserve campaign parameters across redirects so attribution is not lost between surfaces.
- Use database ownership rules rather than relying only on UI-level filtering.
